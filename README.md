# GENESIS AI

**Локальная исследовательская платформа для собственной генерации видео.**

GENESIS — долгосрочный проект по разработке собственной архитектуры text-to-video. Цель — исследовать генерацию пространственно и временно согласованных видеопоследовательностей с локальным исполнением на GPU/CPU, без обязательных облачных API.

> Текущий репозиторий — ранний исследовательский фундамент. Он не содержит обученной модели и пока не генерирует видео качества Seedance. Качество такого уровня требует масштабных данных, обучения и вычислительных ресурсов.

## Принципы проекта

- Собственная архитектура моделей и обучающего кода.
- Использование открытых датасетов только с проверенными лицензиями.
- Локальное обучение и инференс; облачные GPU не являются обязательными.
- Приоритет визуального качества и временной согласованности.
- Поддержка фотореализма и художественных стилей.
- Прозрачные эксперименты, воспроизводимые конфигурации и контрольные точки.

## Генерация изображений — первый практический модуль

В проект добавлен экспериментальный text-to-image pipeline, обучаемый с нуля:
- компактный conditional U-Net;
- совместно обучаемое byte-level представление текста;
- DDPM scheduler и DDIM sampling;
- JSONL датасет изображение/подпись;
- локальные скрипты обучения и генерации.

Подробная инструкция: [docs/IMAGE_GENERATION.md](docs/IMAGE_GENERATION.md).

Это исследовательская базовая модель, а не готовый генератор уровня коммерческих сервисов. До обучения на лицензированном датасете генерация не будет осмысленной.

## Текущий статус

В репозитории находится:
- базовый исследовательский Video Denoiser на PyTorch;
- простой scheduler для диффузионного обучения;
- функция epsilon-prediction loss;
- конфигурация эксперимента и тест формы тензоров.

Это стартовый прототип для низкого разрешения, а не полноценная text-to-video система. На следующем этапе нужны видеодатасет, текстовый энкодер, латентное пространство, temporal/spatial attention, обучение и sampling pipeline.

## Быстрый старт

Требуется Python 3.10+ и PyTorch. Для GPU установите сборку PyTorch, подходящую вашей видеокарте и операционной системе: https://pytorch.org/get-started/locally/

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS:
source .venv/bin/activate

pip install -e ".[dev]"
pytest
```

## Важное ограничение первого прототипа

Текущая модель обрабатывает видео-тензор напрямую и поэтому быстро расходует память. Используйте маленькие тестовые размеры. Для серьёзной генерации потребуется разработать видеокодек/латентное представление и более эффективную архитектуру.
